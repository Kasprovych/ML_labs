# Стиль коду ML_labs

Читач коду — Java-інженер, який вивчає Python і ML. Мета: код читається згори донизу як
пояснення, а не як головоломка. Форматування й більшість правил перевіряє `ruff`
(`uv run ruff format . && uv run ruff check .`) — нижче те, чого лінтер не побачить.

## Будова пакета лабораторної

```
src/mllabs/labs/labNN/
├── lab.py          # клас LabN(Lab): ЛИШЕ перелік Step і короткі методи-кроки
├── config.py       # @dataclass(frozen=True) з усіма параметрами експерименту
├── dataset.py      # завантаження даних           ┐
├── eda.py          # аналіз                       │ по одному модулю на відповідальність;
├── preprocessing.py# перетворення                 │ імена — за змістом лабораторної
└── plots.py        # побудова графіків            ┘
```

- **Одна відповідальність.** Клас або рахує, або малює, або зберігає. Функція, що рахує, повертає
  результат (`DataFrame`, датаклас), а не друкує його і не пише на диск.
- **`lab.py` — оркестратор.** Метод-крок: взяти дані → викликати клас із модуля → зберегти через
  `self._context.artifacts`. Якщо в ньому з'явився цикл чи формула — це логіка, винось у модуль.
- **Залежності через конструктор.** Ніяких глобальних змінних і синглтонів; конфігурацію та
  `random_state` передавай параметрами.
- **Спільне — у спільний пакет.** Потрібне двом лабораторним → `src/mllabs/<домен>/`, не копіювати.

## Java-стиль засобами Python

| Потрібно | Пиши так |
|---|---|
| інтерфейс | `typing.Protocol` (структурний) або `abc.ABC` + `@abstractmethod` |
| незмінний DTO / record | `@dataclass(frozen=True)` |
| enum | `enum.Enum` / `enum.StrEnum` |
| константа | `UPPER_CASE` на рівні модуля; «приватна» — з `_` на початку |
| private-поле / метод | префікс `_` (`self._model`, `def _fit(...)`) |
| `final` метод | `@typing.final` |
| перевизначення | `@typing.override` |
| `Optional<T>` | `T | None` |
| `List<String>`, `Map<K,V>` | `list[str]`, `dict[K, V]`; у параметрах — `Sequence`, `Mapping` |
| checked exception | власний клас винятку з зрозумілим повідомленням українською |

Іменування: `snake_case` — функції, змінні, модулі; `PascalCase` — класи. У ML прийнято `X`/`y`,
але тут пишемо `features` / `target` (або `x_train`, `y_train`) — зрозуміліше новачку.

## Типи та документування

- Анотації типів на всіх параметрах і результатах. `pd.DataFrame`, `np.ndarray`, `tf.keras.Model`.
- Docstring у стилі Google, **українською**, на кожному модулі, класі та публічній функції:

```python
def detect_outliers_iqr(values: pd.Series, factor: float = 1.5) -> pd.Series:
    """Позначає викиди за правилом міжквартильного розмаху (IQR).

    Викидом вважається значення, що лежить далі ніж ``factor * IQR`` від
    першого чи третього квартиля. Метод не припускає нормальності розподілу.

    Args:
        values: Числова ознака.
        factor: Множник розмаху; 1.5 — класичне правило Тьюкі.

    Returns:
        Булева серія: ``True`` для викидів.
    """
```

- Docstring пояснює **що і навіщо** (і ML-зміст методу одним-двома реченнями), коментар у коді —
  **чому саме так**. Не переказуй код словами (`# збільшуємо i на 1`).
- Неочевидну для Java-розробника конструкцію Python (генератор, `*args`, декоратор, розпакування,
  зрізи, broadcasting у NumPy) супроводжуй коротким коментарем при першій появі в лабораторній.
- Усі числові параметри — в `config.py` з поясненням у `Attributes:`, чому таке значення.

## Правила ML-коду

- **Pipeline понад усе.** Препроцесинг + модель збирай у `sklearn.pipeline.Pipeline` /
  `ColumnTransformer`; із SMOTE/ADASYN — `imblearn.pipeline.Pipeline`. Це унеможливлює витік даних.
- `fit` — лише на train. Жодного `fit_transform` на повному датасеті до розбиття.
- `random_state=config.seed`/`context.seed` у кожному розбитті, моделі, семплері.
- Класифікація: `stratify=target`; `StratifiedKFold` у крос-валідації.
- pandas: без `inplace=True` і ланцюгових присвоєнь; повертай нову таблицю. Без циклів по рядках.
- TensorFlow/Keras: модель будує окрема функція/клас-будівник (`build_autoencoder(config) -> Model`);
  навчання — окремо; `History` перетворюй на таблицю та графік; вхідні конвеєри — `tf.data`.
  Імпорт `tensorflow` — усередині модулів, яким він потрібен (він повільний).
- Графіки: функція приймає дані й повертає `matplotlib.figure.Figure`; зберігає — `ArtifactStore`.
  Об'єктний стиль (`fig, ax = plt.subplots()`), підписи осей українською, одиниці виміру.

## Тести

`tests/labs/test_labNN_<модуль>.py`, pytest. Тестуй власну логіку на крихітних синтетичних даних:
форму й типи результату, граничні випадки, відсутність витоку (трансформер не бачив test).
Не тестуй sklearn/TensorFlow і не навчай великі моделі в тестах. Назва тесту — речення:
`test_iqr_marks_values_beyond_fences`.
