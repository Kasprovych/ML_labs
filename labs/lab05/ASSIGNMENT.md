# Лабораторна робота №5

**Етап оцінки та інтерпретації**

## Завдання

1. **Аналіз інтерпретованості ваг.** Для моделі з ЛР №4 проаналізувати математичну інтерпретованість результатів.
2. **Спеціалізований XAI для візуальних даних.** Застосувати відповідні методи пояснюваності для візуальних сцен та локалізації (Integrated Gradients, Grad-CAM для backbone, тощо). Побудувати карти уваги / heatmaps.
3. **Перевірка на адекватність.** Оцінити стійкість та якість пояснень (наприклад, за допомогою Perturbation Analysis — вилучення / зашумлення найважливіших патчів для перевірки зміни reconstruction error).
4. **Дослідження граничних випадків.** Проаналізувати помилкові спрацьовування (False Positives / False Negatives) на динамічному чи неоднорідному тлі. З'ясувати фізичні/структурні причини, чому модель «пропустила» об'єкт або сприйняла зміну освітлення/текстури за аномалію.
5. **Сформувати науковий звіт.** Підготувати детальний аналіз із рекомендаціями щодо меж придатності розробленого методу для розгортання на edge-пристроях у реальному часі.

Кожне завдання можна реалізувати з використанням популярних бібліотек (наприклад, Scikit-learn, TensorFlow, PyTorch) та мови програмування Python.
