# Лабораторна робота №2

**Етап розробки та навчання моделі**

## Завдання

1. Використати підготовлений у ЛР №1 датасет.
2. Навчити 2-3 різні моделі (наприклад, Логістична регресія, SVM, Дерево рішень, Випадковий ліс, Градієнтний бустинг) для вирішення задачі класифікації/регресії.
3. Провести порівняльні експерименти на кількох сценаріях даних:
   - 3.1. Сценарій А: Базові дані (мінімальне очищення).
   - 3.2. Сценарій Б: Повноцінно очищені дані (просунута імп'ютація + кодування + трансформація).
   - 3.3. Сценарій В: Очищені дані + застосування методів аугментації (SMOTE/ADASYN).
4. Оцінити продуктивність кожної моделі за відповідними метриками (Accuracy, Precision, Recall, F1-Score, ROC-AUC для класифікації; MSE, MAE, R2 для регресії).
5. Проаналізувати сильні та слабкі сторони кожного алгоритму.
6. Сформувати підсумковий звіт про стан даних та виконані перетворення.

Звіт повинен містити:

- Порівняльну таблицю результатів моделювання на різних етапах підготовки даних.
- Детальний аналіз того, чи покращила аугментація якість передбачення і за яких умов вона може викликати перенавчання (overfitting).

Кожне завдання можна реалізувати з використанням популярних бібліотек (наприклад, Scikit-learn, TensorFlow, PyTorch) та мови програмування Python.
