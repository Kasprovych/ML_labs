# Лабораторна робота №1

**Етап підготовки та аналізу даних**

## Завдання

### 1. Вибір та обґрунтування датасету

- Обрати складний публічний датасет із табличними даними з Kaggle або UCI Machine Learning Repository.
- Вимоги до датасету:
  - Не менше 10 ознак (числові + категоріальні).
  - Наявність дисбалансу класів (для задачі класифікації) або вираженої асиметрії/мультиколінеарності (для задачі регресії).

### 2. Глибинний дослідницький аналіз (Advanced EDA)

**Аналіз розподілів та кореляцій.** Побудувати матриці кореляцій (Пірсона та Спірмена), виявити мультиколінеарність. Перевірити числові ознаки на нормальність розподілу (візуально та за допомогою статистичних тестів, наприклад, Шапіро-Уїлка або Д'Агостіно).

**Аналіз аномалій та викидів (Outlier Detection).** Порівняти декілька підходів до виявлення викидів: класичний міжквартильний інтервал (IQR), Z-score та ансамблевий метод (наприклад, Isolation Forest або Local Outlier Factor).

### 3. Комплексна обробка та трансформація даних

**Заповнення пропусків (Imputation).** Порівняти базову імп'ютацію (медіана/мода) із просунутою (наприклад, KNNImputer або IterativeImputer / MICE).

**Кодування категоріальних ознак.** Застосувати кодування залежно від типу ознак: Target Encoding або Frequency Encoding для високопотужних категоріальних змінних, та One-Hot Encoding / Ordinal Encoding для інших.

**Нормалізація та геометричні перетворення.** Застосувати масштабування (RobustScaler або PowerTransformer / Box-Cox для усунення скошеності розподілу).

### 4. Аугментація та генерування даних (Data Augmentation & Generation)

**Синтез нових спостережень (для табличних даних).** Застосувати алгоритми передискретизації та аугментації для подолання дисбалансу класів або розширення вибірки: SMOTE, ADASYN, або додавання керованого гаусового шуму крізь розбивку даних.

**Інженерія ознак (Feature Engineering).** Згенерувати нові синтетичні ознаки на основі взаємодії існуючих (нелінійні комбінації, поліноміальні ознаки, агрегації за категоріями).

### 5. Оформлення підсумкового звіту

Звіт повинен містити:

- Опис датасету та результати EDA (з графіками та висновками).
- Обґрунтування вибору методів імп'ютації, кодування та аугментації.

Кожне завдання можна реалізувати з використанням популярних бібліотек (наприклад, Scikit-learn, TensorFlow, PyTorch) та мови програмування Python.
